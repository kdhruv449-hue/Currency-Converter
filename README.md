# Currency-Converter

## Project Overview

Currency Converter is a web-based application developed using **HTML, CSS, and JavaScript**. The application enables users to convert an amount from one currency to another using exchange-rate data retrieved through a currency conversion API.

The project demonstrates the practical implementation of **JavaScript, DOM manipulation, API integration, asynchronous programming, and dynamic user interface updates**.

## Features

* Convert amounts between multiple currencies.
* Retrieve currency exchange rates through an external API.
* Select source and target currencies using dropdown menus.
* Display the converted amount dynamically.
* Provide currency flags for easier identification.
* Simple and user-friendly interface.
* Responsive design for different screen sizes.

## Technologies Used

* **HTML5** – Used to structure the web application.
* **CSS3** – Used for styling and responsive layout.
* **JavaScript (ES6)** – Used for application logic, DOM manipulation, event handling, and API integration.
* **Currency Exchange API** – Used to retrieve exchange-rate data.

## Working

1. The user selects the source currency.
2. The user selects the target currency.
3. The user enters the amount to be converted.
4. JavaScript sends a request to the currency exchange API.
5. The application receives the exchange-rate data.
6. The amount is converted and displayed dynamically.

## Key Concepts Implemented

* DOM Manipulation
* Event Handling
* Fetch API
* Asynchronous JavaScript
* API Integration
* JSON Data Handling
* Dynamic Content Rendering
